# 保锂安 Android V6.6.6 修订版 r2

应用名称及 versionName 保持保锂安 / 6.6.6；versionCode 从12升为13，包名 io.bmsride.monitor 不变。

- 总览：SOC 一位小数，SOC 圆环、百分比、电量进度及功率黄色。实时电池端功率按 BMS 电压×电流计算，显示绝对值并区分充电/放电，不把电机额定功率当作限制。当前电流符号及协议解析保持原样。
- 移除 MOS 温度卡片（保留 MOS 开关及告警信息）；T1–T3 三列等宽，最高红、最低绿、中间白，同温时中性白；缺失不伪造。每串电压带 V。两处压差按毫伏分辨率判定 ≥100mV 红色，否则绿色，缺失灰色。
- GPS：请求系统 GPS_PROVIDER 最短更新间隔（0ms，由手机硬件和系统决定实际频率），逐个处理批量定位，保留每个有效样本的最高速度；最高速度四舍五入为整数，实时速度仍一位小数。不加人为速度补偿。既有35m精度、5s时效和近零过滤保留。不能保证与高德同值；需户外真机比较。1Hz界面和60分钟曲线采样保持不变。
- 暂停 GPS：停止积分、保留已统计的平均耗电，保留续航；有有效电池数据时可按已有平均耗电刷新估算。重置清空里程、耗电、最高速度及曲线，保留最近有效续航并标记“续航(上次估算)”，新行程有有效平均耗电后替换。不同电池地址不继承旧续航。缓存仅在当前监测服务内存内，停止服务/重启不保证保留，旧估算不是实时可行驶距离。

## GitHub 更新
解压 BMS_666_r2_update.zip，上传其中全部目录及文件到现有仓库根目录；另用 build_666_r2.yml 内容覆盖 .github/workflows/build.yml。Actions → Build Android APK v6.6.6 (rev2) → Run workflow → main。下载 BMS-Ride20-Android-v6.6.6-r2 artifact 中 BMS_Ride20_Android_v6.6.6_r2.apk。若临时签名不一致，先备份再决定是否卸载旧版。
