# BMS 随行20 · Android 0.3.6

纯手机版，面向一加 Ace 6 / Android 16、保锂安 LK8625-A66542（LR365V10_N031x）、20 串磷酸铁锂。沿用 Android 包名 io.bmsride.monitor。

## V0.3.6 更新
- 顶部品牌仅保留“保锂安”，移除右侧 BMS 随行20 小字；应用名称不变。
- 三个页面使用同一个容器中的实际页面，手指横向拖动时相邻页同步移动、轻微缩放和淡入淡出，松手按距离/速度平滑吸附；未达到阈值回弹，首尾不循环。保留顶部导航、各页纵向滚动位置、GPS 曲线拖动和容量输入框。
- BLE 仍为8秒无应用层过滤扫描，去重后展示全部结果；已连接和 LK8625 优先，列表最多显示四行，可内部上下滚动，少于四行按实际数量显示。
- GPS 仅采用 GPS_PROVIDER 的速度，定位精度须在25m内、样本不超过3秒；有速度精度时要求误差不超过1.5m/s。连续3个可信运动样本才进入行驶状态，速度低于约2.9km/h或置信不足退出；起步门槛约5–6km/h（随速度误差变化）。静止判定显示0，不积分里程。无效定位显示空值，断点不补算；里程改用有效GPS速度按实际采样间隔积分，不再直接叠加漂移坐标距离。此保守过滤可能漏计慢速挪车及起步前几秒，需真机调整。历史60分钟及BLE能耗配对逻辑保留。

## V0.3.4 保留功能
- 导航只保留总览、行车 GPS、设备。20 串电芯并入总览，4 列 × 5 行圆角卡片，三位小数 V，顶部压差，最高黄色、最低青色；相同电压不作虚假高低标记。
- 设备页采用连接状态卡片、扫描按钮、扫描数量、名称/MAC/RSSI 及独立连接按钮。扫描结果无数量上限（V0.3.6 改为四行内部滚动）。只有 LK8625 名称匹配的设备可连接，其他 BLE 设备仍显示但标记不支持。保持原模型与协议校验。移除演示模式及停止监测服务按钮，同时删除模拟数据生成逻辑。保留断开 BMS 和可选手动容量设置；断开不会关闭后台 GPS，GPS 可在行车页暂停。
- GPS 车速左轴基础刻度 0、15、25、35、45 km/h，超过 45 自动扩展；右轴平均耗电独立自适应。近 60 分钟历史，按约 1Hz 采样，点击/横向拖动查看数值。时间窗保留于运行中的监测服务内存，非永久记录；停止服务/进程后丢失，重置里程同时清空。
- 手机 GPS 提供速度、里程、最高速度、精度；BLE BMS 提供电压、电流、SOC、电芯、温度等。耗电按 BMS 放电功率积分，平均耗电仅统计 GPS 与 BMS 均有效的配对区间，续航为剩余电量与平均耗电估算。数据失效不伪造曲线，缺测处断线，平均耗电至少需要 0.5 km 有效配对距离。GPS 关闭时不继续累计能耗。真实 BMS 协议仍须真机验证，MOS 温度、真实容量若未解码则显示空值（手动容量可作估算）。
- 未更改 BMS 读写请求或保护参数。历史 JK/JBD 解析器仍在内部测试，但无选择入口。

## GitHub Actions
1. 从 V0.3.5 更新时，将增量包解压后上传到现有仓库根目录，覆盖同路径文件；不要上传 ZIP 本身。
2. 手动编辑 `.github/workflows/build.yml`，替换为独立 `build-v0.3.6.yml` 的完整内容（网页上传可能跳过隐藏目录）。
3. Actions → Build Android APK v0.3.6 → Run workflow，main 分支。
4. 成功后下载 artifact `BMS-Ride20-Android-v0.3.6`，解压得到 `BMS_Ride20_Android_v0.3.6.apk`。
5. 默认临时构建密钥跨次不保证一致。签名不同时先备份旧设置，再卸载旧版安装；不要公开私钥。

本地构建：JDK 17、Gradle 8.9、Android SDK 35、build-tools 35.0.0、OpenSSL，执行 `bash build-packages.sh android`。

## 真机验证
车辆静止时操作。打开蓝牙、授权附近设备及精确定位，关闭其他 BMS App 的连接，扫描并选择 LK8625-A66542。核对总览 20 串与原厂软件数值，检查设备滚动、GPS 及断开状态。GPS 及 BMS 有效后才能计算实际平均耗电，不足 60 分钟只显示已有数据。不得将估算续航视为安全保障。
